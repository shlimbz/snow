📲 iPhone 전체화면

iPhone 사파리는 웹 페이지 전체화면을 지원하지 않아요.
대신 홈 화면에 추가해서 열면 주소창 없이 꽉 찬 화면으로 플레이돼요.

  1. 사파리 아래쪽 공유 버튼 ⬆︎ 누르기
  2. 목록을 내려 홈 화면에 추가 누르기
  3. 홈 화면의 우사기 보드 아이콘으로 실행 → 가로로 돌리기

※ 홈 화면 앱과 사파리는 저장 공간이 따로라, 기록·당근이 서로 이어지지 않아요. 한 곳에서만 플레이하는 걸 추천해요.
